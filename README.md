HUB Fashion

A modern clothing store website designed and developed as a front-end course project.

The project focuses on creating a detailed and well-structured fashion store interface using HTML5 and CSS3, with particular attention to layout, spacing, alignment, and visual details.

✨ Features

- Modern clothing store interface
- Structured navigation and page sections
- Product-focused layout
- Detailed product cards and content sections
- Flexbox-based layouts
- CSS Grid-based layouts
- Precise spacing and alignment
- Detailed positioning and styling
- Clean and organized page structure
- Attention to small UI details

🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid

🎨 Design & Implementation

The project was developed with a focus on creating a clean and visually organized clothing store layout.

Key implementation areas include:

- Building complex layouts with Flexbox
- Creating structured sections using CSS Grid
- Managing spacing, sizing, and alignment
- Working with positioning and element placement
- Styling product cards and store sections
- Creating consistent typography and visual hierarchy
- Reproducing detailed UI elements with pure HTML and CSS

📐 Layout

The project includes multiple carefully structured sections, with Flexbox and CSS Grid used to create and organize the different layout patterns throughout the page.

Particular attention was given to:

- Element positioning
- Consistent spacing
- Dimensions and proportions
- Alignment
- Visual hierarchy
- Overall page structure
